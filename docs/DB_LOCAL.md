# Base de datos local

Este repositorio no versiona instrucciones de máquina, rutas personales ni credenciales locales.

Las notas específicas de bootstrap local deben mantenerse fuera del push, por ejemplo en `docs/_local/DB_LOCAL.md` o en tu documentación privada.

La documentación versionada conserva sólo las guías genéricas:

- [docs/MANUAL_DEVELOPER.md](docs/MANUAL_DEVELOPER.md) para setup de desarrollo reproducible.
- [docs/PRIORIDAD_LOCAL_FIRST_DB.md](docs/PRIORIDAD_LOCAL_FIRST_DB.md) para la política operativa de cambios de base.

Si necesitás registrar detalles de tu entorno local, mantenelos en `docs/_local/` o en archivos ignorados por Git.
